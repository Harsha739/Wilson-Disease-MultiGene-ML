# Wilson Disease Detection Using Multi-Gene Sequencing and Machine Learning

## Overview

This project aims to develop a machine learning pipeline for Wilson
Disease detection using multi-gene sequencing data.

The system processes genetic variants, performs annotation and feature
engineering, predicts variant pathogenicity, and combines variant-level
information to generate patient-level predictions.

## Objectives

- Process VCF sequencing files
- Extract genetic variants
- Perform variant filtering
- Annotate variants
- Generate machine learning features
- Perform variant-level pathogenicity prediction
- Analyze multiple genes associated with Wilson Disease
- Aggregate variant-level predictions at patient level
- Build a patient-level machine learning model
- Evaluate model performance
- Provide explainable predictions
- Develop a simple user interface
